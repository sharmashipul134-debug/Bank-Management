# 🏦 Bank Management System

A simple **Bank Management System** developed using Python. This project helps manage basic banking operations such as creating accounts, depositing money, withdrawing money, and checking account details.

## 📌 Features

- Create a new bank account
- View account details
- Deposit money
- Withdraw money
- Check account balance
- Search for an account
- Manage customer information
- Simple and user-friendly interface

## 🛠️ Technologies Used

- **Python**
- **Git & GitHub**
- Python data structures and file handling

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/sharmashipul134-debug/Bank-Management.git
```

2. Open the project folder:

```bash
cd Bank-Management
```

3. Run the Python program:

```bash
python app.py
```

The main purpose of this project is to understand the fundamentals of **Python programming, functions, data handling, and GitHub version control** by building a practical banking application.
